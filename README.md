# 工程费用管理小程序

一个用于管理单个/多个工程项目收支费用的微信小程序。原生开发，数据存本地，无需服务器。

## 快速开始

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版 Stable Build）
2. 打开工具 → 「导入项目」
   - **目录**：选择文件夹 
   - **AppID**：
     - 有自己的小程序账号 → 填入你的 AppID
     - 没有 → 点击「使用测试号」，或注册个人小程序（免费，个人主体即可）后填入
   - 后端服务：选择「不使用云服务」（本项目为本地存储，无需云环境）
3. 点击「导入」，等待编译完成即可在模拟器中预览

> 模拟器机型可在工具栏切换，建议依次测试 **iPhone SE（小屏）→ iPhone 15 Pro Max（大屏）→ iPad（宽屏）** 三种尺寸。

## 功能

| 模块 | 说明 |
|---|---|
| 工程列表 | 新建 / 编辑 / 删除工程；顶部展示所有工程的收入、支出、结余合计；按状态筛选 |
| 工程详情 | 工程信息卡（名称、甲方、工期、状态、备注）+ 收支概览；在「支出 / 收入」tab 点「记一笔」直接记录对应类型，点顶部工程名进入工程设置；在「全部」tab 底部可「导出表格」 |
| 流水明细 | 按日期分组，每天显示当日收支柱小计；点击记录可编辑，长按可删除 |
| 筛选 | 类型（全部/支出/收入）、日期区间、类别、备注关键字，可组合使用；实时显示筛选结果小计 |
| 记一笔 | 支出/收入切换、金额、日期、类别、备注；金额限制两位小数；支持编辑与删除 |
| 类别管理 | 12 个预设支出类别 + 7 个预设收入类别；支持新增、重命名、删除、恢复默认 |
| 导出表格 | 在「全部」tab 底部点击「导出表格」；可单选「全部 / 按月」范围，自定义月份，并勾选导出「全面流水 / 收入 / 支出」（可多选，分别生成独立工作表）；每个工作表首行为项目名（合并标题行），列：费用类别、金额（正数）、收入/支出（填「收入」或「支出」）、日期；导出为 .xlsx。完成后可选「分享给微信好友」；点「保存」时电脑端走系统另存为，手机端调用文档查看器打开（右上角「···」可转发/收藏，文件才找得到） |

## 目录结构

```
cost-manager/
├── app.js / app.json / app.wxss      全局入口、路由、样式变量（颜色/圆角/间距集中定义）
├── project.config.json               项目配置，导入时请替换 appid
├── pages/
│   ├── index/        工程列表（首页）
│   ├── detail/       工程详情页（流水明细、筛选、记一笔入口）
│   ├── record/       记一笔（新增 / 编辑）
│   ├── project/      工程新建 / 编辑
│   └── category/     费用类别管理
├── components/
│   └── record-list/  流水列表组件（含筛选逻辑）
└── utils/
    ├── store.js      数据层：本地存储 CRUD、默认类别、数据导出
    ├── stats.js      统计：汇总、分类聚合、月度趋势、日期分组、筛选
    ├── format.js     金额（分）与日期格式化
    └── xlsx-writer.js 极简 XLSX 生成器（零依赖，手写 ZIP+OOXML，无需第三方库）
```

## 关键设计

**金额精度**：所有金额在系统内部一律以「分」为单位的整数存储与运算（`utils/format.js` 的 `toFen/toYuan`），彻底避免 `0.1 + 0.2` 这类浮点误差。展示时才转为元。

**响应式**：全部使用 `rpx`（750rpx = 屏幕宽度）。针对宽屏做了额外适配：
- 工程列表在 640px 以上自动变两列
- 记一笔的类别网格在 640px 以上每行 6 个
- 768px 以上内容居中，最大宽度 900px，适配 iPad 与 PC 端小程序

**金额展示**：收入/支出金额本身始终为正数，通过颜色区分（收入绿色、支出红色），不再显示 `+`/`-` 号；结余保留正负号。

**数据隔离**：删除工程会级联删除其下所有流水，操作前有二次确认并提示影响条数；删除类别则保留历史记录的名称快照，统计数据不受影响。

## 数据说明

数据通过 `wx.setStorageSync` 存在手机本地：

| Key | 内容 |
|---|---|
| `pcm_projects` | 工程列表 |
| `pcm_records` | 全部流水记录 |
| `pcm_categories` | 支出与收入类别 |

- 单设备使用，**清理小程序缓存或换手机会导致数据丢失**，重要数据建议定期截图或自行导出
- `store.js` 中已封装 `exportAll()`（导出 JSON）与 `clearAll()`（清空），如需备份功能可自行接入

## 后续可扩展

- **多设备同步**：把 `utils/store.js` 内部的读写替换为云开发数据库调用即可，页面层无需改动
- **预算与超支预警**：工程模型加 `budget` 字段，数据页计算已用比例
- **票据照片**：记录上加 `images` 字段，用 `wx.chooseMedia` + 云存储
- **导出账单**：`store.exportAll()` 已有数据出口，接 CSV 生成或 Canvas 长图分享
